# 要件定義:大学・仕事タスク管理サイト

## 目的
- 大学の授業・課題、仕事のタスクを1か所で管理する
- **Web開発の練習**が主目的。Claudeに丸投げせず、理解しながら作る
- 生成AI企業でのインターンに向けて、実務に近い進め方(Git/GitHub、AI駆動開発、LLM活用)を身につける

## 前提
| 項目 | 内容 |
|---|---|
| 利用者 | 自分だけ(ただし今後のためにログイン機能を作る) |
| 端末 | PC・スマホの両方(レスポンシブ対応) |
| 開発者の経験 | Web開発の経験なし |

## 技術スタック
| 役割 | 技術 |
|---|---|
| 言語 | TypeScript |
| フレームワーク | Next.js(App Router) |
| 認証・DB | Supabase(Auth + PostgreSQL、RLSで認可) |
| スタイル | Tailwind CSS |
| バージョン管理 | Git + GitHub(1機能 = 1ブランチ = 1プルリクエスト) |
| デプロイ | Vercel |
| 開発支援 | Claude Code |

---

## フェーズ1:MVP(最初に作る)

### 1. アカウント
- ユーザー登録(メールアドレス+パスワード)
- ログイン/ログアウト
- ログインしていない人はアプリの画面を見られない
- **ユーザーは自分のデータだけを見たり操作したりできる**

### 2. 授業の管理
- 授業の一覧表示
- 授業の登録
- 授業の編集
- 授業の削除
- 授業が持つ情報:**授業名のみ**

### MVPでやらないこと
- メール認証、パスワードリセット
- タスク機能全般(フェーズ2で作る)

---

## フェーズ2:タスク管理(次に作る)
- タスクの追加・編集・削除・完了/未完了の切り替え
- タスクが持つ情報
  - タイトル
  - 締切(日付+時刻)
  - カテゴリ:課題/仕事/その他
  - 授業(任意。課題なら授業にひもづける。仕事タスクにはない)
  - メモ
  - URL(LMSの課題ページなど)
- 一覧の絞り込み(授業別・カテゴリ別)と締切順の並び替え
- 完了したタスクは一覧で非表示にし、「完了済み」に切り替えると見られる
- 締切を過ぎた未完了タスクは赤く表示する

## フェーズ3以降:あとで追加する機能
- 時間割(曜日×時限で授業を登録。授業に教員名・曜日・時限を追加)
- カレンダー表示
- 優先度
- 締切リマインド通知
- 繰り返しタスク(毎週の小テストなど)
- パスワードリセット

### AI機能(LLM活用の練習)
- 課題の説明文を貼ると、やることのリストに分解してタスクを作る
- (余裕があれば)シラバスPDFを読み込み、授業について質問に答える(RAG)

---

## データの関係(概要)
```
ユーザー ─┬─ 授業(MVP)
          │     └─ タスク(フェーズ2:授業にひもづくもの)
          └─ タスク(フェーズ2:授業にひもづかないもの)
```
